Spinner component (decision 0010): React component with three sizes (medium, large, xlarge), four colors (neutral, primary, white, onNeutral), an optional label (right or bottom) and a default "Loading" announcement, built from Blade source with no new tokens. It turns in code and Storybook (960ms, half pace with reduced motion). Storybook Components / Spinner, `docs/spinner.md` generated by `npm run docs:spinner`, and a Figma Spinner page (static component set, 24 variants). Guardrails are pending the designer's confirmation. Approved by Iram Khan, 2026-10-08.
