# Icons

The master record for the icon library. One SVG file per icon, named in kebab-case (`arrow-left.svg`).

- Every drawing is 24 by 24 and uses `currentColor`, so color comes from a token.
- Imported from Blade source: `razorpay/blade`, commit `e914cf6a843193dc5f259aae27027c1dbb3544ea`, `packages/blade/src/components/Icons`. The paths are unchanged. Only the wrapper was replaced, and clip path ids were renamed to `<name>-clip` so two icons on one page cannot collide.
- Excluded on purpose: Razorpay's own brand marks (`razorpay`, `razorpay-x`, `razorpay-trust`, `razorpayx-payroll`, `razorpayx-payroll-filled`). See [decision 0009](../decisions/0009-icon-library.md).
- Docs: [docs/icons.md](../docs/icons.md), generated by `npm run docs:icons` in `packages/ui`. Code and Storybook are built from these files by `npm run tokens`.
