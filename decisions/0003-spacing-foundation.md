## Context

Third foundation of the Craft pilot, after color and typography. It covers spacing, border radius, border width and breakpoints. Values come from Blade source code, which is the final source of truth (see [0004](0004-color-from-blade-source.md)). The Blade Figma file was read for how it exposes these values and differs from the source in border radius and in the size scale, so it was not used for values.

Source: `razorpay/blade`, commit `e914cf6a843193dc5f259aae27027c1dbb3544ea`, files `packages/blade-core/src/tokens/global/spacing.ts`, `border.ts` and `breakpoints.ts`.

## Decisions

| # | Decision |
|---|---|
| 1 | One layer only. These tokens have no primitive layer, so designers and components use them directly. |
| 2 | Spacing: 12 steps, `0` to `11` (0, 2, 4, 8, 12, 16, 20, 24, 32, 40, 48, 56 px). |
| 3 | Radius: 10 tokens, `none`, `2xsmall`, `xsmall`, `small`, `medium`, `large`, `xlarge`, `2xlarge`, `max` (9999px), and `round` (50%). |
| 4 | Border width: 5 tokens, `none`, `thinner` (0.5), `thin` (1), `thick` (1.5), `thicker` (2). |
| 5 | Breakpoints: 6 tokens, `base` (0), `xs` (320), `s` (480), `m` (768), `l` (1024), `xl` (1200), mobile first. |
| 6 | Values are pixels in the tokens and in code (`--craft-spacing-5: 16px`), as in Blade. |
| 7 | In Figma: 26 variables in one collection, `layout`: `spacing/*` (scope GAP only, so a spacing variable offers itself for padding and gaps and not for width or height), `radius/*` (scope CORNER_RADIUS), `border-width/*` (scope STROKE_FLOAT). |
| 8 | Code only, not Figma variables: `radius/round` (Figma has no percent radius) and all breakpoints (Figma has no screen-width variable). |
| 9 | Not in this foundation: sizes (the 79-step `size` scale), icon sizes, opacity, blur, elevation and motion. They come with the components, icons and effects that use them. |

## Exceptions and oddities

- The Blade Figma file names and values radius differently from the source (for example `small` is 2 in Figma and 8 in the source). Source values are used.
- The Blade Figma file has component sizes (for example Button height) as variables with Desktop and Mobile modes. They are not in the source token files (`tokens/global`, `tokens/theme`), so none are recreated here. Component sizes belong to the components.
- Blade's `max` radius is 9999 in the source and 1000 in the Figma file. Source value is used.
- Figma clamps a corner radius to half the shorter side, so `radius/max` renders as a pill.

## Rules confirmed

None yet. Draft rules are waiting for the designer's confirmation and are not saved in `skills/guardrails`:

1. Designers use these tokens only. No hand-typed spacing, radius or border widths.
2. `max` is for pills and `round` is for circles only.
3. Padding, gaps and margins come from the spacing scale only.
