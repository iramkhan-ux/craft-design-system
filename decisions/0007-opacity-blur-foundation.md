## Context

Sixth foundation of the Craft pilot. Values come from Blade source code, which is the final source of truth (see [0004](0004-color-from-blade-source.md)).

Source: `razorpay/blade`, commit `e914cf6a843193dc5f259aae27027c1dbb3544ea`, files `packages/blade-core/src/tokens/global/opacity.ts` and `blur.ts`.

## Decisions

| # | Decision |
|---|---|
| 1 | Opacity: 16 tokens named 0, 1, 50, 100, 200, 300, 400, 500, 600, 700, 800, 900, 1000, 1100, 1200, 1300, with values 0, 0.01, 0.06, 0.09, 0.12, 0.18, 0.24, 0.32, 0.48, 0.56, 0.64, 0.72, 0.8, 0.88, 0.94, 1. |
| 2 | Backdrop blur: 3 tokens, `low` 4px, `medium` 8px, `high` 12px. |
| 3 | One layer only. Opacity is a number from 0 to 1 and blur is in pixels. |
| 4 | Code: CSS variables `--craft-opacity-*` and `--craft-backdrop-blur-*`. |
| 5 | Figma: one new collection `opacity-blur` with 19 number variables, `opacity/<name>` (scope OPACITY, stored as a whole percent) and `backdrop-blur/<name>` (scope EFFECT_FLOAT). Plus an Opacity and Blur page that shows them (specimen). |
| 6 | Icon sizes are a separate foundation. Figma cannot limit a variable to one component, so they will live in their own `icon/size` group, named for icons, and be used only inside the Icon component. |

## Exceptions and oddities

- The names are steps, not percentages. `100` is 0.09, not 100%.
- Blade defines backdrop blur in its theme but not in its CSS variables file. The values are used as the source states them.
- Figma stores opacity as a whole percent (0.09 is 9), so the Figma value is the source value times 100. All 16 values are whole percentages.
