## Context

Seventh foundation of the Craft pilot. Values come from Blade source code, which is the final source of truth (see [0004](0004-color-from-blade-source.md)).

Source: `razorpay/blade`, commit `e914cf6a843193dc5f259aae27027c1dbb3544ea`, file `packages/blade/src/components/Icons/useIconProps/iconSizeMap.ts`. It maps each icon size to a value in `packages/blade-core/src/tokens/global/size.ts`.

## Decisions

| # | Decision |
|---|---|
| 1 | Six icon sizes: `xsmall` 8px, `small` 12px, `medium` 16px, `large` 20px, `xlarge` 24px, `2xlarge` 32px. |
| 2 | The full `size` list (79 raw values, 0 to 1136px) is not published. Blade itself says it is not exposed to users. Decided by the designer. |
| 3 | One layer only. Values are pixels. |
| 4 | Code: CSS variables `--craft-icon-size-*`. |
| 5 | Figma: six number variables `icon-size/<name>` in the existing `layout` collection, scope WIDTH_HEIGHT. Figma cannot limit a variable to one component, so they also show in other width and height fields. Their names and the guardrail say they are for icons only. Plus an Icon size page that shows them (specimen). |

## Exceptions and oddities

- Icon sizes live in Blade's icon component, not in its token files. The component points to the raw size list for each value.
- The six sizes will be bound to the Icon component when it is built.
