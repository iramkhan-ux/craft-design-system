## Context

Fifth foundation of the Craft pilot. Values come from Blade source code, which is the final source of truth (see [0004](0004-color-from-blade-source.md)). The Blade Figma file has no motion variables at all (its 1,456 variables were searched), so the source is the only reference.

Source: `razorpay/blade`, commit `e914cf6a843193dc5f259aae27027c1dbb3544ea`, file `packages/blade-core/src/tokens/global/motion.ts`.

## Decisions

| # | Decision |
|---|---|
| 1 | Duration: 8 tokens, `2xquick` 80, `xquick` 160, `quick` 200, `moderate` 280, `xmoderate` 360, `gentle` 480, `xgentle` 640, `2xgentle` 960 ms. |
| 2 | Delay: 8 tokens, `2xquick` 80, `xquick` 160, `moderate` 280, `gentle` 480, `xgentle` 960, `long` 2000, `xlong` 3000, `2xlong` 5000 ms. |
| 3 | Easing: 7 cubic-bezier curves, each with a stated use from the source: `linear` (marquee, progress bar), `entrance`, `exit`, `standard` (morph), `emphasized` (hover), `overshoot` (toast), `shake` (error states). |
| 4 | One layer only. Time is in milliseconds. Easing is `cubic-bezier(...)`. |
| 5 | Code: CSS variables `--craft-duration-*`, `--craft-delay-*`, `--craft-easing-*`. |
| 6 | Figma: no variables, because Figma cannot use a duration or easing curve as a variable in a design and Blade has none. Figma gets a Motion page that shows the values (specimen only, like the Color and Typography pages). Decided by the designer. |
| 7 | The Storybook samples play while a row is hovered (or has keyboard focus), starting from the beginning each time, and not at all when the person prefers reduced motion. This is only how the preview works, not how the tokens are used. Changed from a Play button on 2026-10-05 at the designer's request. |

## Exceptions and oddities

- `linear` is `cubic-bezier(0, 0, 0, 0)` in the source. It draws as a straight line.
- Delay and duration share the names `2xquick`, `xquick`, `moderate`, `gentle` and `xgentle`, with the same values, but they are separate tokens.
- The source returns a function from the same names on native platforms. Only the web values are used.
- `overshoot` goes past 1 on the curve (y 1.5), so the specimen draws extra room above the line.
