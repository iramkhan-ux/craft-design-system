## Context

Eighth foundation of the Craft pilot, and the first piece of the component hierarchy (icons, then the Spinner, then the Button and IconButton). Values come from Blade source code, which is the final source of truth (see [0004](0004-color-from-blade-source.md)).

Source: `razorpay/blade`, commit `e914cf6a843193dc5f259aae27027c1dbb3544ea`, folder `packages/blade/src/components/Icons` (452 icons). Blade's Figma file was compared by name. It has about 270 icons, all of which are in the source, plus 88 payment-method logos that are not.

## Decisions

| # | Decision |
|---|---|
| 1 | 447 icons: 392 outline and 55 filled. A filled icon is its own icon, as in the source. |
| 2 | Razorpay's own brand marks are left out (5): `razorpay`, `razorpay-x`, `razorpay-trust`, `razorpayx-payroll`, `razorpayx-payroll-filled`. This project is not Razorpay, and its logos in a public repo could look official. `razorpay-trust` also uses gradients and could not follow a color token. Decided by the designer. |
| 3 | Payment-method logos (Visa, Mastercard and others, 88 components in Blade's Figma) are not part of this library. They are multi-color images, not icons. They may become their own foundation later. Decided by the designer. |
| 4 | Each icon is one 24 by 24 drawing in one color. The paths are exactly the source paths. |
| 5 | Names: kebab-case of the source name (`arrow-left`, `battery-100-percent`). Code names follow the source (`ArrowLeftIcon`, `QRCodeIcon`). Two Figma names change to follow the source: `rotate-cw` becomes `rotate-clock-wise` and `rotate-ccw` becomes `rotate-counter-clock-wise`. |
| 6 | Master record: plain SVG files in `icons/`. Code, Storybook and docs are built from them. |
| 7 | Code: React components `<Name>Icon` with `size` (the six icon sizes, default `medium`) and `color` (an icon color token or `currentColor`, default `surface.icon.gray.normal`). Icons are hidden from screen readers unless given an `aria-label`. |
| 8 | Figma: one component per icon on an Icons page, 24px, named `icon/<name>`, with fills and strokes bound to the `surface/icon/gray/normal` variable. The six sizes come from the `icon-size/*` variables on an instance, not from variants (that would be about 2,700 variants). Decided by the designer. |

## Exceptions and oddities

- Four icons are not plain filled shapes: `scissors` and `bluetooth` use strokes, `pin` and `scissors` use a clipping shape, and `dot` is a circle.
- Colors for icons come from the 71 icon color tokens that already exist (`surface.icon.*`, `feedback.icon.*`, `interactive.icon.*`).
