## Context

Fourth foundation of the Craft pilot. Values come from Blade source code, which is the final source of truth (see [0004](0004-color-from-blade-source.md)). The Blade Figma file was read and differs from the source in the number of levels and in every shadow value, so the source was used.

Source: `razorpay/blade`, commit `e914cf6a843193dc5f259aae27027c1dbb3544ea`, file `packages/blade-core/src/tokens/global/elevation/elevation.web.ts`.

## Decisions

| # | Decision |
|---|---|
| 1 | Four levels, as in the source: `none`, `lowRaised`, `midRaised`, `highRaised`. |
| 2 | Each shadow is one layer: offset x, offset y, blur, spread (pixels) and a color. The color points to the color primitive named in the source: `neutral.blueGrayLight.a1106` in light and `neutral.black.100` in dark. |
| 3 | Light and dark values are both recorded in `tokens/elevation.json`. Figma builds light only, as with color. |
| 4 | `_bottomSheet` (a Blade Figma effect style) and `_toast` (a Blade Figma color) are dropped. They are not in the source. Decided by the designer. |
| 5 | Figma: three effect styles, `elevation/lowRaised`, `elevation/midRaised`, `elevation/highRaised`, bound to 12 number variables in the `layout` collection (`elevation/<level>/x`, `y`, `blur`, `spread`, scope EFFECT_FLOAT) and to the color primitive for the shadow color. `none` needs no style. |
| 6 | Code: `--craft-elevation-none`, `--craft-elevation-low-raised`, `--craft-elevation-mid-raised`, `--craft-elevation-high-raised`, used as `box-shadow`. They switch with `data-theme`. |
| 7 | Backdrop blur (4, 8, 12 px) is not part of this foundation. It goes with the opacity and blur foundation. |

## Exceptions and oddities

- `midRaised` has a different shape in light and dark in the source: light is y 16, blur 12, dark is y 2, blur 8. Copied as-is.
- In the source, `lowRaised` and `highRaised` have the same shape in light and dark. Only the color changes.
- Shadow colors are very light in the light theme (6%), so shadows are faint on a white surface.
- The Blade Figma file has different values: for example `lowRaised` is y 2, blur 16 at 9% and `highRaised` is y 16, blur 48 at 18%. Not used.
- The elevation colors removed from color in 0004 are replaced by the shadow color pointers here.
