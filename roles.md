# Roles

## Admin

The Admin is the final approver for every merge and the only person who can change the process itself (sequences, agents, skills, and the rules for rules). There is always exactly one Admin.

## Rollback key phrase

The agreed key phrase is never stored here. Only a scrambled (hashed) version will be stored, added when the rollback process is built.

## Handoff

The current Admin names a successor, who accepts. The current Admin then enters the key phrase. The key phrase is changed, the handoff is logged below, and the Admin and Approver settings are updated.
